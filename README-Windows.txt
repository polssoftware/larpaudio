LarpAudio for Windows

1. Extract all files from LarpAudio-Windows-Local.zip.
2. Install Node.js LTS from https://nodejs.org/ if it is not installed.
3. Double-click Start-LarpAudio.bat. It opens the app in your default browser.
4. Drop in an audio file, preview it, and click Render MP4.

If the browser does not open, copy the localhost URL from the launcher window
into Chrome or Edge. Keep the launcher window open while using LarpAudio.
Close it to stop the server.

Once Node.js is installed, the app runs offline. It requires no npm install
or account. MP4 export requires browser H.264 and AAC support.
